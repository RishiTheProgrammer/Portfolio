## ✨ About

This is my personal developer portfolio, built from scratch with React.

I use this project to showcase what I'm learning, experiment with animations and interactions, and continuously improve my frontend development skills.

The design focuses on a clean interface with motion, smooth scrolling, custom interactions, and a dark/light theme.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/RishiTheProgrammer/Portfolio.git
```

Go into the project:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown by Vite.

---

## 📦 Build

To create a production build:

```bash
npm run build
```

To check the project with ESLint:

```bash
npm run lint
```
